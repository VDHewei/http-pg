HTTP-PG Logo Design Document
============================

## Overview

`assets/logo.svg` 是 HTTP-PG 项目的品牌标志，采用简约扁平风格。

## 布局结构

整个标志分为上下两部分：

```
[HTTP] ──→ [⬡ PROXY] ──→ [PG]
    AES-256     FORWARD    [MySQL]

       HTTP-PG
     DATABASE PROXY
```

## 设计理念

- **简约扁平** — 纯色填充，无渐变、无阴影、无 3D 效果
- **数据管道** — 从左到右的线性数据流叙事
- **三色标识** — 每种颜色代表一个组件角色
- **模块化** — 每个徽章都是独立功能模块

## 图形元素

### 1. HTTP 徽章（左侧，x=244, y=178, 80×80）
- 背景：`#1e293b`（深灰蓝）
- 边框：`#3b82f6`（蓝色，2.5px）
- 文字：`#60a5fa`，18px Bold，"HTTP"
- 表示加密 HTTP 请求的输入端

### 2. 代理节点（中间，六边形）
- 外六边形：`#2d3748` + `#4a5568` 描边
- 内菱形：`#6366f1`（蓝紫色透明度 0.5）
- 中心圆点：`#6366f1`
- 锁形图标（右下角）：`#34d399` 绿色描边，表示加密

### 3. PG + MySQL 徽章（右侧，x=640, y=164, 80×100）
统一在一个竖长徽章中：
- 背景：`#1e293b`
- 边框：`#6b7280`（中性灰，2px）
- PG 文字：`#fbbf24`（橙色），18px Bold
- MySQL 文字：`#22d3ee`（青色），13px Bold
- PG 在上、MySQL 在下，表示双重数据库支持

### 4. 箭头
- **HTTP → Proxy**：`AES-256` 标签（蓝紫色 #6366f1）
- **Proxy → PG/MySQL**：`FORWARD` 标签（橙色 #f59e0b）
- 箭头线：`#4b5563`，3px
- 箭头三角：`#4b5563`

### 5. 底部文字标
- 分隔线：`#374151`，1.5px，从 x=320 到 x=704
- "HTTP-PG"：`#e5e7eb`，52px，字间距 14px
- "DATABASE PROXY"：`#9ca3af`，14px，字间距 8px
- 居中（x=512）

## SVG 结构

```xml
<svg viewBox="0 0 1024 512">
  <rect/>                     <!-- 背景 -->
  <g id="mark">               <!-- 图形标记 -->
    <rect/> + <text/>         <!-- HTTP 徽章 -->
    <line/> + <polygon/>      <!-- 左箭头 -->
    <polygon/>                <!-- 六边形代理 -->
    <line/> + <polygon/>      <!-- 右箭头 -->
    <rect/> + <text/>         <!-- PG+MySQL 合并徽章 -->
  </g>
  <g id="wordmark">           <!-- 文字标 -->
    <line/>                   <!-- 分隔线 -->
    <text/>                   <!-- HTTP-PG -->
    <text/>                   <!-- DATABASE PROXY -->
  </g>
</svg>
```

## 设计迭代记录

| 版本 | 变更 |
|------|------|
| v1 | 卡通动物（大象+海豚）+ 代理服务器，动物太抽象被否决 |
| v2 | 简化几何动物（椭圆+圆形+基本路径），但仍不够清晰 |
| v3 | **现行方案** — 去掉动物，简约扁平数据管道风格。HTTP → 六边形代理 → PG+MySQL 合并徽章 |
